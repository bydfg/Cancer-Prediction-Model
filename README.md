## 🚀 核心亮点
1. **数据中文化映射**：消除了医学专业术语的阅读壁垒。
2. **解决数据泄露**：敏锐发现了“肿瘤分期_IV期”导致的滞后性数据泄露风险，并进行了业务反思。
3. **突破不平衡难题**：引入 SMOTE 过采样与 XGBoost 样本权重双重强化，成功将“复发灶” F1-score 从 0.05 显著提升至 0.19，转移灶 F1-score 稳定在 0.63。
4. **密码学级别安全部署**：采用 AES 对称加密算法对模型权重进行加密，构建了“密文公开、密钥私有”的安全架构，密钥动态注入 Streamlit Secrets，云端内存实时解密推理。
5. **交互式网站落地**：包含 Streamlit 交互界面代码 `app.py`，支持云端实时在线预测。
## 📂 文件说明
*   `app.py`：Streamlit 交互式前端与云端推理代码。
*   `requirements.txt`：云端环境依赖清单（包含 cryptography、xgboost、joblib 等）。
*   `encrypt_models.py`：本地模型 AES 加密脚本。
*   `*.enc`：加密后的模型文件（`cancer_model.enc`、`preprocessor.enc`、`label_encoder.enc`）。
*   `癌症原发，转移，复发分析.ipynb`：完整的本地分析与模型训练代码。
*   `*.png`：核心可视化与评估图表（特征重要性、混淆矩阵、肿瘤纯度分布等）。
