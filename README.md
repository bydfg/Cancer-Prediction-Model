# 基于集成学习算法的癌症样本类型预测分析

## 项目简介
本项目是《智能数据分析综合实训》课程设计，基于随机森林与 XGBoost 算法，对泛癌种样本类型（原发/转移/复发）进行预测。

## 核心亮点
1. **数据中文化映射**：消除了医学专业术语的阅读壁垒。
2. **解决数据泄露**：发现了“肿瘤分期_IV期”的滞后性风险。
3. **突破不平衡难题**：引入 SMOTE 过采样与 XGBoost，将“复发灶” F1-score 从 0.05 提升至 0.18。
4. **交互式网站落地**：包含 Streamlit 交互界面代码 `app.py`。

## 文件说明
- `app.py`：Streamlit 交互式前端代码
- `癌症原发，转移，复发分析.ipynb`：完整的分析代码
- `*.png`：核心可视化与评估图表（特征重要性、混淆矩阵、肿瘤纯度分布等）
